강의 슬라이드 웹앱

교양영어(영어듣기와 말하기 1 · 영어읽기와 쓰기 1) 강의 슬라이드를 만드는 과정을 구글 도구로 옮겼습니다. 단원과 교재 원문을 넣으면 제미나이가 덱을 짜고, 구글 슬라이드(교수용·학생용)와 확인 퀴즈 폼, 수업용 HTML 덱을 드라이브에 저장합니다.

웹앱(단원·교재 내용 입력)→제미나이→구글 슬라이드→퀴즈 폼→드라이브에 저장

각자 배포한 웹앱 주소 (…/exec) 배포 방법

Google Apps Script 웹앱 · GitHub 저장소의 코드를 각자 Apps Script에 올려 배포한 주소로 엽니다(README 「설치」 4번 clasp create-deployment). 구글 계정이 있으면 누구나 열 수 있고, 만든 자료는 여는 사람의 드라이브에 저장됩니다. 처음 열 때 권한 허용 화면이 나오면 [고급 → 이동 → 허용]. 시연용 [예시 채우기] 버튼이 있습니다.

원문을 지키는 방법

  • 프롬프트 규칙: 교재 본문·대본·정답은 넣은 글만. 없으면 [원문 필요] 자리표시자.
  • 코드 검증: 대본 줄, 정답의 근거 문장, 퀴즈 근거, 표현 모음을 원문과 글자 단위로 대조. 없으면 자리표시자로 바꾸거나 빼고 경고를 남김.
  • 영어가 위, 한국어 해설이 아래 · 한 장에 한 호흡 · 섹션마다 지면 장 먼저 · 덱 끝에 과제 섹션(기한 두 번).

시연에서 알게 된 한계

  • 제미나이는 교사용 지도서를 원문 그대로 받아 적지 않음(저작권 보호). 학생용 교재는 받아 적음 → 지도서 대본·정답은 직접 붙여 넣기.
  • 구글 슬라이드는 코드로 오디오를 넣을 수 없음 → ▶ 버튼 연결, HTML 덱에는 플레이어로 삽입.
  • 무료 등급 음성 사용량 · Apps Script 6분 제한 → 단계 나누기, 섹션 동시 생성, 긴 음성은 조각으로 만들어 잇기.

무료 등급 제미나이는 입력이 구글 서비스 개선에 쓰일 수 있어, 실제 학생 정보는 넣지 않습니다.
