강의 슬라이드 만들기

단원과 교재 원문을 넣으면 제미나이가 슬라이드를 짜고, 구글 슬라이드(교수용·학생용)와 확인 퀴즈 폼을 드라이브에 저장합니다.

웹앱 입력→제미나이→구글 슬라이드→퀴즈 폼→드라이브 저장

Gemini API 키

Google AI Studio(aistudio.google.com)에서 만든 키. 이 스크립트에만 저장됩니다.

확인 중…

무료 등급에서는 입력한 내용이 구글 서비스 개선에 쓰일 수 있습니다. 실제 학생 정보는 넣지 마세요.

1 · 단원과 교재 내용

교재 본문·대본·정답은 여기 넣은 글만 씁니다. 없는 것은 지어내지 않고 [원문 필요] 자리표시자로 둡니다.

지난 입력을 불러왔습니다

교재 파일로 넣기 — 선택. 고르고 [원문 읽기]를 누르면 아래 칸이 채워집니다

PDF·사진은 제미나이가 지면을 보고 받아 적고, Word는 글을 그대로 꺼냅니다. 받아 적은 글은 꼭 훑어보고 틀린 곳을 고쳐 주세요. 지면 사진(jpg·png)은 교재 지면 장에 그대로 들어갑니다.

교재 지면PDF 또는 쪽별 사진
교사용 지도서대본·정답·해설 상자 · 저작권 보호로 거절되면 아래 칸에 직접 붙여넣기
교안Word(.docx)·PDF
파일마다 30초–2분. 올린 파일은 드라이브 강의자료/_올린 파일/ 에 보관됩니다.
    영상 넣기 선택 — 유튜브 링크나 드라이브 영상 링크. 슬라이드 안에서 바로 재생됩니다
    보통 5–10분. 제미나이가 붐비면 더 걸립니다. 창을 닫지 마세요.

    이전 결과 다시 열기

    이미 만든 자료를 열어 영상을 넣거나 HTML 덱을 다시 만듭니다. 제미나이 글 생성은 다시 하지 않습니다.

    2 · 진행 상황

    단계마다 결과 폴더의 작업기록에 저장되므로, 멈추면 그 단계부터 다시 할 수 있습니다.

      3 · 결과

      섹션 요약 영상 자동 제작

      제미나이가 섹션마다 복습 대본(영어 + 한국어 자막)을 쓰고, 음성을 붙여 이 화면에서 바로 녹화합니다. 만든 영상은 섹션 끝에 자동으로 들어갑니다. 녹화는 재생 시간만큼 걸리니(섹션당 1분 안팎) 이 창을 앞에 띄워 두세요. 무료 음성 사용량이 찼으면 자막만 있는 영상으로 만듭니다.

        NotebookLM 동영상 개요로 잇기

        1. 입력 기록 문서를 엽니다 — 교재 원문·대본·정답이 들어 있습니다.
        2. NotebookLM에서 새 노트북 → 자료 추가 → Google Drive → 그 문서를 고릅니다.
        3. 동영상 개요를 만들고 내려받아 드라이브(이 결과 폴더 등)에 올린 뒤, 링크를 아래에 붙여넣습니다.
        제미나이 글 생성은 다시 하지 않습니다 · 약 1–2분 · 교수용·학생용 슬라이드와 퀴즈 폼을 새로 만듭니다

        학생에게 나눠 줄 때는 드라이브의 영상·음성 파일(또는 결과 폴더)을 “링크가 있는 모든 사용자 — 보기”로 공유해야 학생 화면에서 재생됩니다.
